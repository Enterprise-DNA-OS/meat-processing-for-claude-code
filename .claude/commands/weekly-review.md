description: The Monday plant review, written from the attention list, the money owed to producers and producer performance.
---

Run `npm run plant -- attention --json`, `npm run plant -- due --json`, `npm run plant -- supply --json` and `npm run plant -- performance --json`. Write a one-page review to `drafts/weekly-review-<date>.md`: last week's kill and value, what is owed to producers and what is late, settlements held and why, traceability reports outstanding, the week ahead against capacity, producers to talk to about bruising or condemnations, and the boning yield. Plain sentences, numbers in tables. Never sent from here.
