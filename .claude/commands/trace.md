description: Kill dates not yet reported to NLIS or NAIT as slaughtered, and how close each is to the 48-hour limit.
---

Run `npm run plant -- trace --json`. Lead with anything late. After the operator uploads the kill to NLIS or NAIT, record it with `npm run plant -- reported <kill date> [--species=] --ref=<upload reference> --actor="Name"`. This system never uploads anything itself.
