---
description: Record a mob arriving at the yards, with its vendor declaration.
---

Ask for the booking, head received, dead on arrival, the declaration number (NVD or ASD), whether the declaration says any animal is inside a withholding period or ESI, the pen and when they were last fed. Run `npm run plant -- arrive <booking> --head= --doa= --declaration="NVD ..." [--not-clear] --pen= --last-fed="YYYY-MM-DD HH:MM" --actor="Name"`. Never record a declaration number the operator has not read off the form. If there is no declaration, say plainly that the mob is held.
