description: Carcases no grid line fits, with the nearest line, so a price can be agreed.
---

Run `npm run plant -- off-grid --json`. For each, show the carcase and the nearest grid line. The price is agreed with the producer by a person; record it with `npm run plant -- price <booking> <body> --cents=<c/kg> --reason="..." --actor="Name"` only when the operator gives the agreed price.
